# 学生选题系统（TopicGo）

《软件工程》实践课程项目 —— 公正公开的课设在线选题平台。

## 项目背景

课程课设选题长期存在"顺序不透明、名额易超卖、统计靠手工"的痛点。本系统提供**四种选课策略**（先到先得 / 绩点优先 / 多志愿分配 / 随机抽签）、**并发防超卖**、**候补自动/手动递补**、**全程操作日志留痕**与**管理员登记制登录**，让选题公平高效、全程可追溯、可审计。

## 角色与数据归属

- **管理员**：仅平台账户管理（登记/停用/重置密码/删除），为分学生配指导教师，不涉及课程业务；
- **教师**：仅管理自己发布的课题与自己的选题轮次，只能看到自己的学生；
- **学生**：仅能看到自己指导教师的开放课题，未开放前不可见。

## 核心设计

- **四种选课策略**：先到先得（拼手速）、绩点优先（按绩点放行）、多志愿分配（平行志愿 + 绩点优先）、随机抽签（公开种子，可复现审计）；
- **并发防超卖**：`BEGIN IMMEDIATE` 事务 + 部分唯一索引，多人同时抢题不超卖、不重复选；
- **递补策略**：退选后可按"自动递补 / 教师手动递补 / 不递补"处理，防恶意退选；
- **防反复退选**：每轮每生退选次数上限（教师撤销不计入）、截止前 N 小时禁止退选、退选原因必选并写入日志，三重防护可轮次级配置；
- **学业数据与前置要求**：教师维护学生的绩点与各科成绩；课题可设「前置要求」（人话描述 + 课程分数门槛），学生选课前可见自身匹配情况；教师可按前置门槛退课，学生立即收到含原因与建议的站内通知；
- **全程留痕**：选题、退选、递补、分配、抽签全部写入操作日志；退选不删记录，"选课与退选记录"永久可查；
- **权限管控**：不提供公开注册，仅管理员登记的用户可登录，支持账号停用；
- **师生归属**：学生绑定指导教师，只能看到自己老师的开放课题；教师只能管理自己的课题、轮次与学生；管理员只负责账户不涉及课程；
- **多班级管理**：教师可管理多个班级，课题按「面向班级」发布，仅对应班级学生可见（不选=面向所有班级）；
- **多轮次管理**：教师可创建多个选题轮次（第一轮/补选轮），最新轮次即时生效，历史轮次可查看；
- **课题开关**：课题可随时关闭/重新开放，关闭后学生不可见（有选题记录的题目不能删除，只能关闭）；
- **误提交补救**：教师可撤销学生误提交的志愿/报名/候补记录，学生即可重新提交，全程留痕；
- **自助改密**：所有角色可自行修改密码（需验证原密码），管理员亦可重置；
- **安全防护**：全站表单 CSRF 令牌校验、密码哈希存储、登录仅限登记账号；
- **内置使用说明**：各关键页面带「📖 使用说明」折叠面板（怎么发布、怎么选、各模式解释）；
- **分组轮选**：可限制仅指定班级参与某一轮次；
- **角色工作台**：师生登录后各进入自己的 Dashboard（待办、倒计时、进度、公告），教师可发布公告、查看“我的学生”选题进度（红色行=未选题），页面自适应手机。
