# 学生选题系统（TopicGo）

《软件工程》实践课程项目 —— 公正公开的课设在线选题平台。

## 项目背景

课程课设选题长期存在"顺序不透明、名额易超卖、统计靠手工"的痛点。本系统提供**规则化选题**（先到先得 / 绩点优先）、**并发防超卖**、**候补自动递补**、**实时监控导出**与**结果全员公示**，让选题公平高效、全程可追溯。

## 核心设计

- **并发防超卖**：`BEGIN IMMEDIATE` 事务 + 部分唯一索引 `(ROUND_ID, USER_ID) WHERE STATUS='confirmed'`，多人同时抢题不超卖、不重复选；
- **绩点优先模式**：高绩点未选同学优先，低绩点同学需等待；
- **候补递补**：退选后候补队列首位自动递补；
- **窗口控制**：仅轮次开放且处于起止时间内允许选题。
