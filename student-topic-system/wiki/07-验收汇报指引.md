## 三、主要关键技术（主要框架、实现语言、数据组织等）

| 项 | 内容 |
| --- | --- |
| 实现语言 | Python 3.12 |
| Web 框架 | Flask 3（Jinja2 模板 + 原生 CSS，一个 `.venv/bin/python src/app.py` 即可运行） |
| 数据组织 | SQLite（WAL 模式）；9 张表 + 统一五公共字段；ER 图见设计报告 |
| 安全 | Werkzeug 密码哈希 + Session + CSRF 令牌 |
| 核心机制 | `BEGIN IMMEDIATE` 事务串行化并发写；部分唯一索引 `(ROUND_ID, USER_ID) WHERE confirmed` 防重复选题 |
| 关键算法 | 先到先得 / 绩点优先 / 多志愿平行分配 / 随机抽签（公开种子可复现）；候补自动/手动递补 |

详细设计（架构、ER、算法伪码、接口表）：`design/设计报告.md`。
