# 05 用户使用说明

## 一、学生使用说明

1. **登录**：打开系统地址，输入学号（或登录名）与初始密码 `123456`；
2. **浏览题库**：在"浏览题库"页查看全部题目，可按关键词、标签、难度筛选；留意"已选/剩余"列了解名额情况；
3. **选题**：点击"选题"按钮并确认。注意：**每人限选 1 题**；
4. **候补**：题目满员时点击"加入候补"，获得候补序号；有同学退选时按队列自动递补；
5. **查看与退选**：在"我的选题"查看结果；如需退选点击"退选"（名额将递补给候补首位）；
6. **结果公示**：在"结果公示"页查看全员选题结果。

## 二、教师使用说明

1. **登录**：使用工号登录；
2. **题库维护**：新增/编辑/删除题目，设置人数上限、标签、难度；已有选题记录的题目不可删除；
3. **选题轮次**：设置轮次名称、选题规则（先到先得 / 绩点优先）、选题起止时间、候补开关、轮次状态；
4. **选题监控**：实时查看各题已选/剩余/候补人数与完成率；
5. **导出结果**：点击"导出 CSV"下载选题结果存档。

## 三、常见问题

| 问题 | 解答 |
| --- | --- |
| 提示"当前不在选题窗口期" | 请联系教师确认轮次的开始/截止时间 |
| 提示"每人限选1题" | 需先在"我的选题"退选后才能选其他题目 |
| 绩点优先模式下无法选题 | 还有绩点高于你的同学未选题，系统会按绩点依次放行 |

## 四、获取方式

- 在线体验：`https://building-weeks-give-herein.trycloudflare.com`（公网临时地址，供小组测试与交叉评估）
- 系统内还可查看：项目主页（`/home`）、原型演示（`/prototype`）、使用流程（`/guide`）
- 本地部署：`pip install -r requirements.txt && python app.py`，浏览器访问 `http://localhost:5000`
- 正式环境：部署到云服务器后替换为固定地址（发布页面保留至少 1 个月备查）
