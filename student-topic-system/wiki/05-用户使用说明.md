# 05 用户使用说明

## 一、学生使用说明

1. **登录**：打开系统地址，输入学号（或登录名）与初始密码 `123456`；
2. **浏览题库**：在"浏览题库"页查看全部题目，可按关键词、标签、难度筛选；留意"已选/剩余"列了解名额情况（老师未开放轮次时题库不可见）；
3. **选题**：点击"选题"按钮并确认。注意：**每人限选 1 题**；
4. **候补**：题目满员时点击"加入候补"，获得候补序号；有同学退选时按队列自动递补；
5. **志愿填报/抽签报名**：多志愿或抽签模式下，在"志愿填报"页提交志愿或报名；
6. **查看与退选**：在"我的选题"查看结果；如需退选点击"退选"（名额将递补给候补首位）；
7. **结果公示**：在"结果公示"页查看全员选题结果；
8. **查看前置要求**：浏览题库时每个课题显示「前置要求」及你的成绩是否匹配（不满足也能选，但教师核验后可能退课）；
9. **查看通知**：左侧「🔔 通知」（带红点为未读）查看教师退课提示，含退课原因、成绩明细与老师建议；
10. **修改密码**：点击右上角「🔒 修改密码」，验证原密码后可设置新密码（至少 6 位）。

## 二、教师使用说明

1. **登录**：使用工号登录；
2. **题库维护**：新增/编辑/删除题目，设置人数上限、标签、难度；已有选题记录的题目不可删除，但可「关闭」（下架，学生不可见），之后可随时「开放」；
3. **选题轮次**：设置轮次名称、选题规则（先到先得 / 绩点优先 / 多志愿 / 随机抽签）、选题起止时间、候补开关、递补方式、分组班级等；没有轮次时点「+ 新建轮次」创建，可创建多个轮次（最新轮次即时生效）；
4. **选题监控**：实时查看各题已选/剩余/候补人数与完成率；执行志愿分配/公开抽签、手动递补；学生误提交志愿/报名时可在「待分配/待抽签名单」或「候补名单」中点「撤销」，学生即可重新提交；
5. **录成绩/绩点**：在「我的学生」点「录成绩/绩点」维护学生各科成绩与绩点（用于绩点优先、志愿分配与前置要求核验；挂科红色标出）；
6. **设前置要求**：发布/编辑课题时可填「前置要求」（人话描述 + 课程分数门槛），学生选课前即可看到是否匹配；
7. **前置退课**：「选题监控 → 已选/候补名单与前置核验」中红色行=不满足前置要求，点「退课」填写原因与建议，学生立即收到站内通知；
8. **导出结果**：点击"导出 CSV"下载选题结果存档；
6. **公告**：在"公告管理"发布公告，展示在你名下学生的首页。

## 三、常见问题

| 问题 | 解答 |
| --- | --- |
| 提示"当前不在选题窗口期" | 请联系教师确认轮次的开始/截止时间 |
| 提示"每人限选1题" | 需先在"我的选题"退选后才能选其他题目 |
| 绩点优先模式下无法选题 | 还有绩点高于你的同学未选题，系统会按绩点依次放行 |
| 看不到任何课题 | 你的老师尚未开放选题轮次，或课题未面向你的班级开放，请联系老师 |
| 志愿/报名填错了 | 联系教师在「选题监控 → 待分配/待抽签名单」中撤销，即可重新提交（教师撤销不占用你的退选次数） |
| 退选被拒绝（次数用尽/临近截止） | 属防反复退选策略，请联系任课教师处理 |
| 教师提示"尚未创建选题轮次" | 在「选题轮次」页点击「+ 新建轮次」创建即可 |
